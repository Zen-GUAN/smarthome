# 巴法云QPS限流 → 小爱"服务器离线" 调研结论 (2026-09-06)

## 症状
小爱语音控灯，刚"开灯"马上"关灯"（间隔1~2秒）几乎必报"服务器离线"；
单独、间隔久的指令正常。

## 根因（官方FAQ实锤）
来源：巴法官方FAQ https://cloud.bemfa.com/docs/src/faq.html
（docs.bemfa.com 新版SPA文档"常见问题"同内容）

原文：「默认采用有QPS限制的共享mqtt服务器(普通服务器)，用户多时或操作频繁时
可能触发QPS限制，此时设备会临时离线，一般几秒钟即可恢复。
解决办法：提升为尊享贵宾(VIP)服务，享受无限制频繁操作服务。」

机制：连发指令触发QPS → 设备在巴法/米家侧"临时离线"数秒 →
窗口内米家云的控制调用失败 → 小爱播报离线类错误。

## 本地实测（脚本 scripts/qps_rapid_test.py）
- HTTP API 0.4秒间隔连发3条ping（不动设备）：全部 code=0，
  HA接收自动化正常触发
- 结论：巴法→HA的MQTT腿不限流；限的是米家云→巴法智能家居控制接口那条腿
  （无法本地复现，只能语音实测）

## 解决办法
1. 官方正解：巴法控制台升VIP（入口 www.bemfa.com/vip，需登录），
   解除频繁操作限制
2. 免费缓解：两条语音指令间隔≥3秒；可让HA的/up状态回传延迟3~5秒减少突发
   消息（未实施）
3. 若已开VIP仍复现：需继续查（届时怀疑/up回传竞态或控制台服务器类型设置）

## 附：topic类型不符也会报离线（另一类原因，本案例已排除）
类型不匹配时米家报"该设备已被移除下线或产品已下架"，属持续性离线。
